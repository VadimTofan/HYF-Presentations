Conditions

A condition chooses which code runs.
Its result is treated as true or false.

How if / else works

if (condition) {
  // Run this code when the condition is true.
} else {
  // Run this code when the condition is false.
}

if

Checks the condition. Runs its code block if the result is true.

else

Runs its code block if the condition is false. This part is optional.

Make a decision

const age = 14;

if (age > 18) {
  console.log("Allowed");
} else {
  console.log("Denied");
}

Only one code block runs. What happens when age is 18?

How else if works

if (firstCondition) {
  // Run if the first condition is true.
} else if (secondCondition) {
  // Run if the first is false and the second is true.
} else {
  // Run if both conditions are false.
}

Check from top to bottom. Run the code block for the first true condition, then skip the rest.

More than two choices

const age = 14;

if (age < 13) {
  console.log("Child");
} else if (age < 20) {
  console.log("Teenager");
} else {
  console.log("Adult");
}

JavaScript runs the code block for the first true condition.

AND. OR. NOT.

&& - AND

Both conditions must be true.

|| - OR

At least one condition must be true.

! - NOT

Reverse a boolean value.

!! - DOUBLE NOT

Reverse twice: true stays true, false stays false.

console.log(14 >= 13 && 14 < 20); // true
console.log(14 < 18 || 14 === 18); // true
console.log(!true);               // false
console.log(!!true);              // true

if (isAdmin) {
  console.log("You are in charge");
} else if (isLoggedIn) {
  console.log("Welcome user");

  console.log("Welcome guest");

Functions

A function is a reusable piece of code.
Define it once. Call it when you need it.

You already use functions

const randomNumber = Math.random();
const maxNumber = Math.max(3, 5);

console.log(randomNumber); // between 0 and 1
console.log(maxNumber);    // 5

The parentheses call the function.

The parts of a function

function name(parameter) {
  // body
}

Keyword: function

Starts the function definition.

Name

The name you choose for the function.

Parameters

Inputs the function can receive.

Body: { ... }

The instructions that run when the function is called.

Define. Then call.

function greet() {
  console.log("Hello, HackYourFuture!");
}

greet();
greet();

Defining a function does not run its body.

Parameters & Arguments

function greet(name) {
  console.log("Hello, " + name);
}

greet("Sana");
greet("Peter");

Parameter

name is the placeholder in the function definition.

Argument

"Sana" is the actual value supplied in a call.

Return a value

function sum(a, b) {
  return a + b;
}

const returnedSum = sum(5, 10);
console.log(returnedSum); // 15

The call produces a value. The variable stores it.

Arrow functions

const greet = () => {
  console.log("Hello, HackYourFuture!");
};

greet();
greet();

Same greeting, different syntax. Call it the same way.

Follow the value

Call

sum(5, 10)

→

Return

return 15

→

Store

returnedSum is 15

Use the returned value in another calculation.

const doubledSum = returnedSum * 2;
console.log(doubledSum); // 30

Printing and returning

function printSum(a, b) {
  console.log(a + b);
}

function getSum(a, b) {
  return a + b;
}

const printed = printSum(5, 10); // prints 15
const returned = getSum(5, 10);  // returns 15
console.log(printed);           // undefined
console.log(returned);          // 15

Forgetting return

function sumNoReturn(a, b) {
  a + b;
}

const result = sumNoReturn(5, 10);
console.log(result); // undefined

Calculating a value does not automatically return it.

Return ends the call

function getAccessMessage(age) {
  if (age < 18) {
    return "Denied";
  }

  return "Allowed";
}

console.log(getAccessMessage(14)); // Denied
console.log(getAccessMessage(18)); // Allowed

Conditions in functions

function isAuthenticated(userRole) {
  const isAdmin = userRole === "admin";
  const isLoggedIn = userRole !== "guest";

  if (isAdmin) {
    return true;
  } else if (isLoggedIn) {
    return true;
  }

  return false;
}

console.log(isAuthenticated("guest")); // false
console.log(isAuthenticated("admin")); // true

Use early returns

function isAuthenticated(userRole) {
  const isAdmin = userRole === "admin";
  const isLoggedIn = userRole !== "guest";

  if (isAdmin) return true;

  if (isLoggedIn) return true;

  return false;
}

console.log(isAuthenticated("guest")); // false
console.log(isAuthenticated("admin")); // true

Each return stops the function. No else is needed.

A method is a function accessed through a value or object.

const message = "  hello  ";

console.log(trimmedMessage); // "hello"

trim() returns a new string. Capture that value.

Scope

Scope determines where a variable name
can be used in your code.

Global and local scope

const course = "HackYourFuture";
// course is outside the function.
function introduce() {
  const name = "Sana";
  // name belongs to the function.
  console.log(course);
  console.log(name);
}

introduce();
console.log(course);

A block has boundaries

if (true) {
  const blockMessage = "Inside the block";
  console.log(blockMessage);
}

// Run separately to investigate the error:
// console.log(blockMessage);

let and const belong to the block where they are declared.

Lexical scope

function outerFunction() {
  const message = "Hello from the outer function";

  function innerFunction() {
    return message;
  }

  return innerFunction;
}

const readMessage = outerFunction();
console.log(readMessage());

Exercise: scope

const global = "global";

function scopeTest() {
  console.log(localScope);
  console.log(global);
  const localScope = "localScope";

  function tester() {
    console.log(global);
    const testerVariable = "testerVariable";
  }

  tester();
  console.log(testerVariable);
}

Scope: investigate one
step at a time

  1. The first log fails: localScope is used before its const declaration.
  2. Move its declaration above the log. Run again.
  3. The next error is testerVariable outside tester().
  4. Keep that log inside tester(), where the variable exists.

Corrected Example

const global = "global";

function scopeTest() {
  const localScope = "localScope";
  console.log(localScope);
  console.log(global);

  function tester() {
    const testerVariable = "testerVariable";
    console.log(global);
    console.log(testerVariable);
  }

  tester();
}

scopeTest();

For loops

Repeat a block of code
while a condition remains true.

For loop parts

for (index; condition; update) {
  console.log("hello");
}

Index

let i = 0 runs once before the loop.

Condition

i < 3 is checked before each repetition.

Update

i++ adds 1 after each repetition.

Trace the counter

for (let i = 0; i < 3; i++) {
  console.log(i);
}

// 0
// 1
// 2

The loop stops before printing 3.

Infinite loops

A loop keeps repeating if its condition never becomes false.

// The counter update is missing!
for (let i = 0; i < 3;) {
  console.log(i);
}

Why? How to fix it?

i stays 0, so i < 3 stays true. Add i++ after the second semicolon.

String logger: solution

function logString(string, repetitions) {
  for (let i = 0; i < repetitions; i++) {
    console.log(string);
  }
}

logString("hello", 3);
logString("hello", 0);

This function prints messages. It does not return a result.

Build and return

function spam(number) {
  let repeated = "";

  for (let i = 0; i < number; i++) {
    repeated = repeated + "hello";
  }

  return repeated;
}

console.log(spam(0)); // empty string
console.log(spam(1)); // hello
console.log(spam(3)); // hellohellohello

Visit every array item

const recipients = ["Sana", "Peter", "Anna"];

for (let i = 0; i < recipients.length; i++) {
  const recipient = recipients[i];
  console.log(recipient);
}

Indexes start at 0. The last index is length − 1.

String to list

const emailList = "sana@gmail.com|peter@gmail.com";
const recipients = emailList.split("|");

console.log(recipients);
// ["sana@gmail.com", "peter@gmail.com"]

split("|") separates the text at each | and returns an array.
