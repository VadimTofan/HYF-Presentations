Objects

Keep related information in one value.

  • A user: name, age, role.
  • A product: name, price, inStock.
  • A house listing: address, rent, rooms.

How to write an object

const objectName = {
  key: value
};
  • const objectName declares a variable for the object.
  • { } contain the object's properties.
  • Each property is a key: value pair.
  • Use a colon between key and value, and commas between properties.

Keys & values

const user = {
  name: "Emil",
  age: 25,
  role: "Teacher",
};

console.log(user);

name is a key. "Emil" is its value.

Objects can hold any value

const user = {
  name: "Emil",                             // string
  age: 25,                                  // number
  isTeacher: true,                          // boolean
  skills: ["JavaScript"],                   // array
  address: { city: "Copenhagen" },          // nested object
  greet: function () { return "Hi!"; },     // function
  manager: null,                            // null
  nickname: undefined,                      // undefined
};

Mix value types in one object.

How to read

const user = {
  "name": "Emil",
  age: 25,
};

console.log(user.name);
console.log(user["name"]);

Prefer dot notation for a known key that is a valid JavaScript identifier.

When to use brackets

const listing = {
  address: "Nørrebrogade 10",
  "monthly rent": 8500,
};

console.log(listing["monthly rent"]);

const property = "address";
console.log(listing[property]); // "Nørrebrogade 10"
console.log(listing.property);  // undefined

Use brackets for keys with spaces or keys stored in variables.

Add. Update. Delete.

const user = { name: "Emil", age: 25 };

user.age = 26;
user.lastName = "Bay";
delete user.lastName;

console.log(user);

The same object now has a different age.

const & objects

const product = { name: "Notebook", price: 30 };
product.price = 35;

const topics = ["HTML", "CSS"];
topics.push("JavaScript");

console.log(product.price, topics.length);

const prevents reassignment. Contents can change.

Values can be nested

const user = {
  name: "Emil",
  classes: ["JavaScript 1", "JavaScript 2"],
  hobbies: { favourite: "computers" },
};

console.log(user.classes[0]);
console.log(user.hobbies.favourite);

Read one level at a time: object → value → property or index.

Four methods to remember

Beginning

unshift(item) → add
shift() → remove

End

push(item) → add
pop() → remove

Adding returns length; removing returns an item.

What does splice do?

const array = ["Emil", "Ahmad", "Zoey"];

array.splice(from which position, how many items)

Remove an item with splice

const names = ["Emil", "Ahmad", "Zoey"];

const removed = names.splice(1, 1);

console.log(names);   // ["Emil", "Zoey"]
console.log(removed); // ["Ahmad"]

Find a position with indexOf

const names = ["Emil", "Ahmad", "Zoey"];

console.log(names.indexOf("Ahmad")); // 1
console.log(names.indexOf("Amina")); // -1

const index = names.indexOf("Ahmad");
if (index !== -1) {
  names.splice(index, 1);
}
console.log(names); // ["Emil", "Zoey"]
  • Returns -1 if the item is absent.

Recap: objects & keys

An object keeps related values together as key: value pairs.

const user = { name: "Emil", age: 25 };
const key = "name";

console.log(user.name);    // Emil
console.log(user["name"]); // Emil
console.log(user[key]);    // Emil
console.log(user.key);     // undefined

Use dots for a known key. Use brackets when the key is stored in a variable or contains spaces.

Recap: change an object

Assign a value to update a property or add a new one. Use delete to remove a property.

const user = { name: "Emil", age: 25 };

user.age = 26;
user.city = "Copenhagen";
console.log(user.city); // Copenhagen

delete user.city;
console.log(user.age);  // 26
console.log(user.city); // undefined

Recap: records & loops

An array can hold objects. Read the array item first, then its property.

const students = [
  { name: "Emil", skills: ["HTML", "CSS"] },
  { name: "Zoey", skills: ["JavaScript"] }
];

for (let i = 0; i < students.length; i++) {
  const student = students[i];
  console.log(student.name, student.skills[0]);
}
// Emil HTML
// Zoey JavaScript

Recap: array beginnings & ends

push / pop work at the end. unshift / shift work at the beginning.

const names = ["Emil", "Zoey"];

console.log(names.push("Amina"));    // 3
console.log(names.pop());            // Amina
console.log(names.unshift("Ahmad")); // 3
console.log(names.shift());          // Ahmad

console.log(names); // ["Emil", "Zoey"]

All four methods change the array. Adding returns the new length; removing returns the removed item.

Recap: find & remove

includes checks whether an item is present. indexOf finds its position.

const names = ["Emil", "Ahmad", "Zoey"];
console.log(names.includes("Ahmad")); // true
console.log(names.indexOf("Amina"));  // -1

const index = names.indexOf("Ahmad");
if (index !== -1) {
  const removed = names.splice(index, 1);
  console.log(removed); // ["Ahmad"]
}
console.log(names); // ["Emil", "Zoey"]

The call stack

Which function is running?
Where does execution continue when it finishes?

Follow two calls

function a() {
  b();
  return "a";
}
function b() {
  return "b";
}
console.log(a());

When b returns, a resumes at the next line.

Watch the return value

function double(number) {
  return number * 2;
}
function makeTotal(price) {
  const total = double(price);
  return total + 5;
}
console.log(makeTotal(10));

A call pauses makeTotal. A return supplies the value 20.

Follow a function call

function greet() {
  console.log("Hello!");
}

function start() {
  console.log("Before");
  greet();
  console.log("After");
}

start();
