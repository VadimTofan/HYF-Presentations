Variables

A variable connects a useful name to a value.

Declaration, assignment, use

let score;          // declaration
score = 10;        // assignment
console.log(score); // use
Create a name
Store a value
Read the value

const, let, and var

const

Default choice. The variable cannot be assigned another value.

let

Use when the variable must receive a new value later.

var

Older declaration style. Recognize it, but do not use it in new code.

Naming variables

const courseName = "HackYourFuture";
let completedExercises = 0;

completedExercises = 1;

console.log(courseName);
console.log(completedExercises);

Value types

The type determines what a value
represents and how it behaves.

Check types with typeof

console.log(typeof "Vadim");  // "string"
console.log(typeof 37);     // "number"
console.log(typeof true);   // "boolean"

typeof produces a string describing the value’s type.

Working with strings

const name = "Vadim";

console.log(name[0]);          // "V"
console.log(name.length);      // 5
console.log(name.toLowerCase()); // "vadim"

Indexes begin at 0, so the first character uses index 0.

Booleans: true or false

Investigate

Find one real situation where software needs a yes/no value.

Explain

const isTakeaway = true;

Arrays

const shoppingList = ["eggs", "apples", "flour"];

console.log(shoppingList[0]); // "eggs"
console.log(shoppingList[2]); // "flour"
console.log(shoppingList[3]); // undefined: no item at this index

Array indexes start at 0, just like string indexes.

Compare values

A comparison asks a question and produces a boolean.

What is an operator?

It is a symbol that performs an operation on values.

console.log(10 + 5); // 15

Here, + is the operator. It adds the values 10 and 5.

  • = assign a value to a variable
  • + add   - subtract
  • * multiply   / divide
  • % find the remainder after division

Equality operators

console.log(7 == "7");   // true: conversion occurs
console.log(7 === "7");  // false: type differs
console.log(7 != "7");   // false
console.log(7 !== "7");  // true

Use === and !== so value and type must agree.

Assignment and equality

  • = assigns a value
  • == equals
  • === strictly equals
  • != does not equal
  • !== strictly does not equal

Strict comparisons do not convert value types.

Compare numbers

console.log(8 > 3);   // true
console.log(8 >= 8);  // true
console.log(3 < 8);   // true
console.log(3 <= 2);  // false

Arithmetic

Operators combine values to produce a new value.

Arithmetic operators

console.log(10 + 5); // 15
console.log(10 - 5); // 5
console.log(10 * 5); // 50
console.log(10 / 5); // 2

Add numbers or join text?

console.log(2 + 3);          // 5
console.log("Hello, " + "Vadim"); // "Hello, Vadim"
console.log("Total: " + 5); // "Total: 5"

When either side is a string, + joins text.

The remainder operator

console.log(21 / 5); // 4.2
console.log(21 % 5); // 1 remainder
console.log(8 % 2);  // 0: evenly divisible

Investigate: how could remainder tell whether a number is even?

JavaScript errors

Read from the error type to the filename and line number.

Reading error messages

ReferenceError: pizzaPrice is not defined
    at Object.<anonymous> (pizza.js:4:20)
  1. Name the error: ReferenceError.
  2. Compare the variable spelling with its declaration.
  3. Change one thing and run the file again.

Common errors

SyntaxError

JavaScript cannot understand the written structure. Check quotes, brackets, and punctuation.

ReferenceError

A requested variable name cannot be found. Check declaration and spelling.

Unexpected result

The program runs but the value is wrong. Use console.log() to display intermediate values and types.

Pizza project

Combine variables, value types, arithmetic, and console.log() in pizza.js.

Pizza order: part 1

  1. Create a folder named pizza-exercise.
  2. Create pizza.js inside it.
  3. Use console.log() to display I love pizza and run the file with Node.js.
  4. Store your favourite pizza name and its price in variables.
  5. Use console.log() to display: New pizza order: [name]. The price of the pizza is: [price]. Replace [name] and [price] with your stored values; do not print the square brackets.

Part 1: solution

console.log("I love pizza");

const pizzaName = "Margherita";
const pizzaPrice = 85;

console.log(
  "New pizza order: " + pizzaName +
  ". The price of the pizza is: " + pizzaPrice
);

Pizza order: part 2

  1. Store the number of pizzas.
  2. Store whether the order is takeaway.
  3. Calculate totalPrice.
  4. Use console.log() to display the takeaway choice, quantity, pizza name, and total.
  5. Change the unit price and verify the total changes correctly.

Part 2: solution

const pizzaName = "Margherita";
const pizzaPrice = 85;
const pizzaAmount = 3;
const isTakeaway = true;
const totalPrice = pizzaPrice * pizzaAmount;

console.log(
  "New pizza order (takeaway:", isTakeaway, "):", pizzaAmount, pizzaName,
  ". Total cost for the order is:", totalPrice
);
